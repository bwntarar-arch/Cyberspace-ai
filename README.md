CyberSafe AI

About the Project

CyberSafe AI is a beginner cybersecurity project designed to identify possible phishing warning signs in text messages.

How It Works

The current prototype checks message text for suspicious keywords, urgency, prize-related claims, and links. It displays a warning when listed warning signs are detected.

How to Use

1. Open the project webpage.
2. Enter or paste a message into the checker.
3. Run the check.
4. Review the result.

Current Limitations

This prototype uses rule-based keyword checks. It does not yet use an AI model, and it may produce false positives or miss phishing messages. A message marked safe is not guaranteed to be safe.

Future Improvements

- Integrate an eligible open-source or open-weight AI model.
- Test with legitimate and phishing examples.
- Improve detection and explain the reasons for each warning.
